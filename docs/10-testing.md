# 10 · 测试计划与验收矩阵

## 1. 测试层级

- 单元：加密字节协议、严格输入验证、客户端状态机、错误重试分类、计时边界。
- 集成：真实 PostgreSQL 事务/锁/迁移、用户隔离、会话撤销、事件/配额原子性、通知中断。
- 跨端：Windows 与 Android 对相同加密向量互解、实际系统剪贴板与生命周期测试。
- 系统：HTTPS 域名/IP/私有 CA、自托管安装、备份恢复、签名升级、网络与进程故障。

测试数据只用专用账号和虚构文字。不要把真实剪贴板、恢复码或服务器凭据传到 CI 日志。

## 2. 核心用例

| ID / 需求 | 场景 | 预期 |
| --- | --- | --- |
| T01 / FR-01 | 域名、IPv4、IPv6、端口、无协议、非法 path | 地址正确规范化；不跨 origin 转发凭据 |
| T02 / FR-01 | 自签错误 CA、IP SAN 不匹配、过期证书、HTTP 降级 | 明确失败；无跳过校验自动重试 |
| T03 / FR-02/03 | A 用户读/删/恢复 B 的条目、设备或扫描 token | 全部拒绝，不泄露存在性 |
| T04 / FR-02 | 并发刷新、旧 token 重用、响应丢失、设备撤销 | 单次轮换；重用撤销；不无限保留旧 token |
| T05 / FR-04 | 双设备同时初始化保险库 | 仅一份成功，另一端绝不覆盖已有密钥 |
| T06 / FR-04 | 双端互解；改 nonce/tag/AAD/账号/来源设备 | 正确文本一致；篡改全部拒绝并隔离 |
| T07 / FR-04/12 | 错 RK、RK 丢失、Keystore 失效、Windows 用户变化 | 不输出乱码/假成功；按说明重新解锁 |
| T08 / FR-05 | 中文、emoji、RTL、组合字符、空格、CRLF/LF、超长文字 | 原样保留有效文本；64KiB 边界，超限不截断 |
| T09 / FR-05 | 空字符串、HTML+text、图片/文件、敏感标记 | 空跳过；只收 text；非文字不上传；敏感默认跳过 |
| T10 / FR-06/11 | A 写入导致 B 监听，B 再通知 A | 不形成循环；相同文字稍后人工复制仍可同步 |
| T11 / FR-11 | 服务器提交后断响应，源端重试 10 次 | 一个条目、一个 create 事件、固定原创建收据 |
| T12 / FR-11 | A 持锁未提交，B 同账号提交请求 | B 等待，不出现游标跨过未提交序号 |
| T13 / FR-11 | 漏 WSS 提示、断线、进程重启、本地事务前后崩溃 | 增量补齐；游标与缓存一致；无重复正文 |
| T14 / FR-11 | 手机离线复制旧文，电脑在线复制新文，然后重连 | 旧文进入历史，不能自动覆盖电脑新剪贴板 |
| T15 / FR-11 | 接收拉取期间用户本机又复制 | generation 防护，本地复制不被慢响应覆盖 |
| T16 / FR-11 | 超过 30 天离线后上线，旧历史已 purged | 全量校准删除旧缓存，不从缓存创建新 outbox |
| T17 / FR-11 | 扫描分页时新增/删除/恢复，日志过期或 epoch 改变 | H 后事件收敛；失效扫描重来；本地待上传队列保留 |
| T18 / FR-07 | 只下载部分历史时搜索、锁定后搜索 | 显示覆盖范围；不宣称全云端结果；锁定无明文索引 |
| T19 / FR-08/09 | 删→重复删→恢复→再删；并发状态修改 | 版本冲突明确；重复删除不延期；重新删除重算期限 |
| T20 / FR-09/10 | 到期前 1ms、等于到期、超过到期；锁等待跨过边界 | 持锁后以 DB 时钟判断；过期不恢复、不下载密文 |
| T21 / FR-10 | 恢复与 worker 同时操作、worker 中途崩溃 | 仅一个最终状态；事务回滚后可重试；无重复 purge |
| T22 / FR-10/11 | 手动 purge 后 60 天重放原 create | 只返回原收据/墓碑，不恢复密文 |
| T23 / FR-05/08 | 并发写入刚好触及条数/字节额度 | 不越额；回收站计入；删除/清理仍可执行 |
| T24 / FR-12 | 扫描 DB/WAL/日志/缓存/崩溃报告 | 不含测试正文、CMK、RK、令牌明文；系统剪贴板除外 |
| T25 / FR-13 | 新主机部署、端口不通、证书续期、数据库断开 | 文档步骤准确；ready 与失败状态准确 |
| T26 / FR-13 | 从旧备份恢复并重设 epoch/撤销会话 | 重新登录和校准；明确报告备份之后的数据损失 |

## 3. Android 真机矩阵（M0 必须完成）

每个单元格记录“读是否允许 / 写是否成功 / 网络到达时延 / 系统粘贴结果”，并附 API、targetSdk、机型、ROM、输入法、权限和重现步骤。空格不等于通过。

| 状态 | 普通应用 | 默认 IME | 必测影响 |
| --- | --- | --- | --- |
| Activity 前台有焦点 | 待实测 | 待实测 | 自己/远端写入是否被再次上传 |
| 前台无焦点/分屏 | 待实测 | 待实测 | onResume 与焦点不同 |
| 其他应用前台、键盘展开 | 后台读预期受限 | 待实测 | 系统长按粘贴与 IME 候选点击分别测试 |
| 普通后台、屏幕开启 | 待实测 | 待实测 | 网络和写权限分别测 |
| 锁屏 / Doze / App Standby | 待实测 | 待实测 | 挂起与延迟；不以重试掩盖 |
| 强制停止 / 系统杀进程 / 重启 | 待实测 | 待实测 | 恢复路径，不承诺自动唤醒 |
| 拒绝通知 / 电池受限 / 无 GMS | 待实测 | 待实测 | 普通前台路径仍可用 |
| IME 切回第三方键盘 | 不适用 | 待实测 | 能力立即降级，不继续声称全自动 |

系统基线至少覆盖 API 29、33、35、36 和发布时最新稳定 API；机型至少 Pixel/AOSP 与两类目标市场厂商 ROM。不能只用模拟器验证厂商后台行为。

## 4. 负载与故障测试

按需求基线压测 100 在线设备、10 写/秒，统计 P50/P95/P99、失败率、内存、CPU、数据库锁等待和磁盘增长。测试常用 4 KiB 及最大 64 KiB 文字，不能用空包替代。达到时延指标须限定两端运行状态。

故障注入：断 TCP、丢 WebSocket 通知、响应超时、服务器提交后退出、PostgreSQL 重启、磁盘满、手机暂停、时钟偏移。客户端时间偏移不影响全局顺序或 7 天边界。观察恢复后的最终状态和用户提示，不能只检查返回码。
