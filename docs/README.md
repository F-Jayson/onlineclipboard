## 已采用的设计决定

| 决策 | 选择及理由 | 代价 |
| --- | --- | --- |
| 原生客户端 | Windows WPF、Android Kotlin，便于访问平台剪贴板和生命周期 | 两套界面与同步状态机，靠契约及互通测试防止差异 |
| 服务端 | Go 单体 + PostgreSQL，HTTP 拉取 + WebSocket 提醒 | 首版单实例；水平扩容以后增加跨实例消息分发 |
| 加密 | 客户端 AES-256-GCM，服务端仅持有密文和必要元数据 | 无服务端全文搜索；新设备可用登录密码解锁，恢复密钥作备用 |
| 自托管 | 自有域名或 HTTPS IP，客户端配置服务器根地址 | IP 证书及私有 CA 信任需部署者配置 |
| Android | 普通模式为可交付基线；默认输入法为可选增强研究项 | 无法承诺普通应用全后台无感同步 |
| 历史正文 | 首版不可原地编辑，编辑后保存为新条目放入后续版本 | 避免正文版本与加密 nonce 管理复杂化 |
| 排序 | 服务端同账号事务序号，客户端时间只作展示 | 同账号写入串行，符合个人剪贴板负载 |
| 回收站 | 服务端时间 + 168 小时；删除事件与内容清理分开 | 需保留无正文的墓碑防止旧设备复活数据 |
| 搜索 | 已缓存条目的本地搜索，展示覆盖范围 | 首次下载未完成时搜索并不完整 |
| 推送 | 首版不强制依赖 FCM 或厂商服务 | Android 后台送达不具备秒级保证 |

## 设计变更规则

- 协议字段以 [OpenAPI](../contracts/openapi.yaml) 为机器可读草案，[同步协议](04-sync-protocol.md) 和 [安全设计](03-security.md) 规定跨字段语义。冲突需同时修改，不能让客户端自行猜测。
- 上线前冻结协议 v1 与加密格式 v1，补充实际双端互通向量。变更加密字节布局必须提高格式版本。
- 所有平台判断记录系统、targetSdk、厂商、运行状态及证据。系统升级后复测；参考 [官方资料](11-references.md)。
- 不确定项已经安排到里程碑，不阻止文档与骨架交付：输入法体验、Android 后台写入兼容性、依赖与签名发布、实际资源和时延指标。
